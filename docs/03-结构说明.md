# 口袋 CPM · 结构与技术说明

> 版本 **1.0.1**（versionCode 40，minSdk 28 / targetSdk 34）· APK 约 17 MB（不含模型）· 文档更新于 2026-10-30

---

## 1. 定位与技术栈

一台安卓手机上的**完全离线 AI 聊天应用**。会话即联系人，支持多人群聊；模型、语音、数据全部在本机，除 `127.0.0.1:8080` 外不发起任何网络请求。

| 层 | 选型 | 说明 |
|---|---|---|
| 界面 | 原生 JS 单文件（无框架、无构建、无 npm） | `app/assets/index.html`，3072 行 |
| 桥接 | `@JavascriptInterface` 注入 `window.Koudai` | 20 个方法 |
| 原生 | Java（无 Gradle，自建 aapt2 + javac + d8 流水线） | 4 个类，2413 行 |
| 推理 | llama.cpp b11669（`libllamaserver.so`，arm64） | 文本 CPU / 视觉 Adreno OpenCL |
| 语音 | sherpa-onnx + onnxruntime | SenseVoice int8 识别、VITS 16k 朗读 |
| 模型 | MiniCPM-V 4.7 1B Q4_K_M + mmproj | 672 MB + 1.06 GB |
| 存储 | WebView localStorage（会话）+ 应用私有目录（模型） | 无数据库、无账号 |

## 3. 分层架构

```
┌──────────────────────────────────────────────────────────────┐
│ 界面层   WebView  file:///android_asset/index.html            │
│ 原生 JS 单文件 3072 行；四页 + 七个底部面板；无第三方依赖         │
├──────────────────────────────────────────────────────────────┤
│ 桥接层   window.Koudai（20 个 @JavascriptInterface 方法）        │
│ 设备信息 / 语音 / 分享 / 导入 / 存档 / 引擎控制                  │
├──────────────────────────────────────────────────────────────┤
│ 原生层   MainActivity 1786 · SpeechEngine 396                  │
│          EngineHolder 68（进程内单例）· EngineService 163（保活） │
├──────────────────────────────────────────────────────────────┤
│ 推理层   libllamaserver.so → 子进程，监听 127.0.0.1:8080          │
│          文本 CPU · 视觉 Adreno OpenCL                          │
│ 语音层   sherpa-onnx（SenseVoice 识别 + VITS 朗读）              │
└──────────────────────────────────────────────────────────────┘
```

**进程模型**：App 主进程（WebView + 语音）→ 启动 `llama-server` **子进程**（引擎）→ 前台服务保活，退出界面不杀引擎，达成"热启动秒开"。引擎在后台闲置 60 分钟或用户点通知「结束引擎」时释放。

## 4. 数据模型

一条 session 既可能是「联系人（单聊）」也可能是「群聊」，用 `kind` 区分：

| 字段 | 适用 | 说明 |
|---|---|---|
| `id` | 全部 | 时间戳 + 随机后缀，避免同毫秒碰撞 |
| `kind` | 全部 | `single` / `group` |
| `title` | 全部 | 联系人名 / 群名，**全局不重名**（@ 依赖名字唯一） |
| `avatar` | 全部 | 预设头像（dataURL）或相册导入（256 px JPEG dataURL） |
| `persona` / `memory` | single | 人设、长期记忆，每次请求注入 system |
| `voice` / `read` | single | 音色 key、自动朗读开关（每人独立） |
| `notes[]` | single | 记忆卡 `{id, text, at}`，一条 ≤60 字，≤30 条 / 合计 900 字 |
| `members[]` | group | 联系人 id 列表，2–10 人 |
| `lastWho` | group | 上一位发言人；没 @ 时由它接话 |
| `msgs[]` | 全部 | `{role, text, img, ts, who?, stat?}`，`who` 仅群里有 |
| `at` | 全部 | 最近活动时间，用于列表排序 |

**上限常量**：`MAX_MEMBERS = 10`、`MAX_CONTACTS = 300`、`MAX_GROUPS = 40`（保存时校验，不只靠界面禁用）。

**持久化**：`localStorage["pocketcpm.v1"] = { sessions, opts }`；迁移标记 `pocketcpm.mig`。

## 5. 前端结构（app/assets/index.html）

### 5.1 页面

| id | 内容 |
|---|---|
| `#s-home` | 消息列表：会话按 `at` 倒序，群聊带"N 人"标签与"发言人：预览"；长按删除 |
| `#s-contacts` | 「联系人 / 群聊」双标签（带数量）+ 搜索框（只按名字） |
| `#s-chat` | 聊天页：群聊顶部成员条；气泡上方显示发言人；空聊天只显示头像 + 名字 + 人设 |
| `#s-model` | 模型卡片与能力说明（只展示 1B） |
| `#s-settings` | 生成 / 多模态 / 外观与数据 / 关于 |

### 5.2 面板（sheet）

`newSheet`（新建菜单：添加联系人 / 创建群聊）、`contactSheet`（新建/编辑联系人）、`groupSheet`（建群/群设置）、`msgSheet`（长按消息）、`noteSheet`（存为长期记忆）、`confirmSheet`（通用确认）、`importMask`（导入进度）。

### 5.3 函数地图

| 分组 | 代表函数 | 职责 |
|---|---|---|
| 存储 | `load / save / migrateNames / archivePayload` | 读写 localStorage；配额不足丢最老 12 张图重试；一次性纠正旧自称；存档序列化 |
| 列表 | `renderHome / renderContacts / refreshLists` | 消息页、联系人页（双标签 + 搜索） |
| 聊天渲染 | `renderChat / msgNode / renderWelcome / renderMemberStrip` | 气泡、发言人标签、成员条、空态 |
| 发送 | `send / replyOne` | `send` 排队（可 @ 多人），`replyOne` 单次：占位 → SSE 流式 → 落库 → 朗读 |
| 身份 | `systemPrompt / fixSelfName` | 私聊/群聊两种 system；把"我是别人"纠正回自己 |
| 群 | `membersOf / mentionedAll / openGroupSheet / saveGroup` | 成员解析、@ 匹配（长名优先）、建群改建群 |
| 音色 | `VOICES / applyContactVoice / previewVoice` | 音色跟人走；同音色不重载 |
| 记忆 | `saveNote / renderNotes` | 记忆卡增删、注入 |
| 交互 | `bindLongPress / bindMention / askConfirm` | 长按删除（480 ms）、点头像/长按头像 @、二次确认 |

### 5.4 关键流程

**启动**：`load()`（补字段 + 一次性纠正自称）→ `renderHome` → 原生侧解模型/初始化语音 → `probe()` 探活 → 顶部绿点。

**发送（单聊）**：push 用户消息 → 占位气泡 → `systemPrompt`（人设 + 长期记忆 + 记忆卡 + 名字锁定）→ 最近 9 条历史 → SSE 流式 → `fixSelfName` → 落库 → 可选朗读。

**提示词行为（1.0.1 起）**：system 末尾注入手机本地日期与时刻（每次请求现取），并明确四条硬规则——不自我介绍、只有被问才报名字、不复述用户的话、不把对方的状态写成自己；附一条示例压住“我也累”这类镜像。用户消息尾部不再注入身份提醒（那是“每句都自我介绍”的直接原因）。

**图片内存保护**：长边上限 1280，另有总像素上限 1.2 MP；按可用内存自动降级（<1.8 GB → 896，<1.3 GB → 768，<1.0 GB 直接拒收）；发送前二次校验；识图请求失败且引擎被回收时自动重启引擎并提示。

**发送（群聊）**：`mentionedAll` 解析 @（可多个）→ 逐个 `replyOne`；每位用自己的人设/记忆/音色；**历史里别人的话放用户侧并加名字**，只有自己的话是 `assistant`，避免身份串味；上下文收窄到 7 条。

**删除**：长按行 → 确认框（联系人会提示"还在 N 个群里"）→ 同步清理群成员与 `lastWho`。

**导入**：设置选 zip → 原生流式解压 → 校验 manifest 与路径（禁 `..`）→ 增量覆盖（大小一致则跳过）。

**存档 / 恢复**：
- 导出：`archivePayload()` → 180 KB 分片 → `archiveFinish` 一次写盘 → `Download/口袋CPM/koudai-存档-时间戳.json`
- 恢复：SAF 选文件 → 原生读入（≤40 MB）→ 页面分片取回 → 校验 `app`/`sessions` → **先自动导出当前数据** → 覆盖 → 补字段 → 刷新
- 分片原因：避免数 MB 字符串一次性跨 WebView 桥导致卡顿或失败

### 6.2 引擎启动参数

```
-m 1B.gguf -mm mmproj.gguf --host 127.0.0.1 --port 8080
-c 8192 --cache-type-k q8_0 --cache-type-v q8_0
-t 4 -ngl 0 --mmproj-offload
```

- **8192 tokens 上下文**，KV cache q8 量化（同样内存装两倍上下文）
- 实测引擎 RSS ≈ 928 MB，系统剩余 ≈ 2.6 GB
- **失败自动回退**：8192 起不来 → 4096 + 关闭量化 → 再不行退回纯 CPU（关 OpenCL），保证一定可用

### 6.3 语音子系统

| 能力 | 模型 | 位置 |
|---|---|---|
| 识别 | SenseVoice int8 + tokens | `files/speech/asr/`（229 MB） |
| 朗读 | VITS 16k，6 音色 | `files/speech/{tts,tts_m,tts_bronya,tts_theresa,tts_zzl,tts_doom}/` |

音色表：`female`（女声·温柔）、`bronya`（女声·清冷）、`theresa`（女声·活泼）、`male`（男声·标准）、`zzl`（男声·沉稳）、`doom`（男声·低沉）。后四个来自音色包，缺失时自动退回 `female`。

## 8. 打包与签名

**流水线**（`app/build-apk.sh`，六步）：

```
[1/6] aapt2 编译资源        [2/6] 生成 R.java
[3/6] javac 编译 Java       [4/6] d8 转 dex
[5/6] pack.py 组装 APK      [6/6] zipalign + apksigner 签名
```

```bash
cd /d/kcpm      # ASCII 别名，等价于 D:\口袋CPM\project
BUNDLE_MODELS=0 TARGET_SDK=34 OUT_NAME=koudai-cpm-1.0.1-lite.apk bash app/build-apk.sh
```

- `BUNDLE_MODELS=0` 出轻量包（模型另导入）；`=1` 会把模型分片打进 APK（体积约 1.8 GB）
- `pack.py` 的原生库来自 **`app-ocl/`**（含 OpenCL）+ `speech/libs/`（onnxruntime、sherpa-jni）
- **签名密钥固定在 `project/app/koudai.keystore`**（alias `koudai` / `koudai123`）。**绝不能放进 `build/`**——`build/` 每次构建被清空，会导致签名变化、无法覆盖安装（已踩过此坑）

## 9. 权限与安全

**权限**（`AndroidManifest.xml`）：

| 权限 | 用途 |
|---|---|
| `INTERNET` | 仅访问 `127.0.0.1:8080` |
| `RECORD_AUDIO` | 语音输入 |
| `FOREGROUND_SERVICE` / `..._DATA_SYNC` | 引擎保活 |
| `POST_NOTIFICATIONS` | 通知栏「结束引擎」 |
| `WRITE_EXTERNAL_STORAGE`（maxSdk 28） | 旧系统导出存档 |

**已实施的安全措施**：

- `shouldOverrideUrlLoading` 白名单：只放行 `file:///android_asset/`、`127.0.0.1:8080`、`about/data/blob`，其余拦截并记录日志（防止远端页面拿到原生桥）
- Markdown 渲染**先转义再处理格式**，不生成 `<a>`/`<img>`，模型输出无法注入 HTML/JS
- 导入 zip 校验 manifest 与 `..` 路径穿越
- 存档恢复前校验 `app` 标识，并自动备份当前数据

**已知取舍**：引擎监听 127.0.0.1 且**未设 api-key**（同机其它应用理论上可访问）；加 `--api-key` 可能影响 `/health` 探活，列入下版本评估。

## 12. 已知限制

1. **引擎无鉴权**：见第 9 节，建议下版本加 `--api-key` 并适配探活。
2. **上下文 8192 tokens**（约 3000 汉字）+ 仅带最近 9 条（群里 7 条）：长对话靠"人设 + 长期记忆 + 记忆卡"维持连续性，不是全量历史。
3. **localStorage 约 5–10 MB**：图片多时会自动丢弃最老的 12 张，属预期行为。
4. **切音色阻塞约 1 秒**：同步加载模型，体验问题非缺陷。
5. **1B 能力上限**：复杂推理、长文分析偏弱；群聊多人时偶有口吻漂移（已有三层名字锁定兜底）。
6. **无云备份**：卸载即丢内部数据；请用「导出存档」+ 模型 zip 备份。
7. **35B 代码保留但禁用**：本机 11 GB 内存跑不动，需 16 GB 以上机型，当前版本不开放入口。
8. **仅 arm64**：不支持 32 位设备与模拟器 x86。
