# 口袋 CPM · 使用说明

> 适用于 **1.0.0**（versionCode 39）。全部推理在手机本地完成，不联网、不上传。

---

## 1. 这是什么

一台安卓手机上的**离线 AI 聊天软件**。它把"会话"做成"联系人"：每个 AI 是一个有名字、有头像、有人设的独立角色，可以单聊，也可以把多个角色拉进群里聊。

- 模型：MiniCPM-V 4.7 **1B**（Q4_K_M），文字与看图都支持
- 语音：SenseVoice 识别（说话变文字）、VITS 朗读（6 个音色）
- 数据：全部存在手机里，卸载前请先导出存档

**能做什么**：日常问答、写作、翻译、算数、看图片（截图、票据、说明书）、口述输入、朗读回复、多角色群聊。

**不适合做什么**：复杂推理、长文档分析、专业领域知识——1B 模型的定位是"随手可用的离线助手"，不是云端大模型。

## 2. 安装与首次使用

### 2.1 安装 APK

| 项目 | 说明 |
|---|---|
| 安装包 | `koudai-cpm-1.0.0-lite.apk`（约 17 MB） |
| 要求 | Android 9 及以上（minSdk 28），arm64（64 位）机型 |
| 权限 | 无需联网权限；仅旧系统（Android 9 及以下）导出存档时申请存储权限 |

点击安装即可。首次打开会看到"引擎正在准备"，此时还没有模型，界面能进但对话不可用。

### 2.2 导入模型包（必须，只做一次）

1. 把 `koudai-models-1.0.0.zip`（约 1.8 GB）放进手机任意目录，记住位置；
2. 打开 App → 底部「**设置**」→ 外观与数据 → 「**模型包**」→ 点「**导入 .zip**」；
3. 选文件，等待解压（约 2–4 分钟，屏幕别熄）；
4. 完成后「设置 → 关于」里的本地占用会显示约 1.7 GB，引擎会自动启动。

模型包含：文本模型 672 MB + 视觉投影器 1.06 GB + 语音识别 228 MB + 两个内置音色各 116 MB。

### 2.3 导入音色包（可选）

`koudai-voices-1.0.0.zip`（约 476 MB）提供额外 4 个音色。同样是「设置 → 音色包 → 导入 .zip」。

导入后「音色包」一行会显示"全部 6 个音色已就绪"。不导入也能用，只是只有 2 个内置音色。

### 2.4 升级

直接覆盖安装新 APK 即可，**模型、聊天记录、联系人都保留**（签名已固定）。

## 3. 界面总览

底部四个标签：

| 标签 | 作用 |
|---|---|
| **消息** | 所有会话按最近活动排序；群聊带"N 人"标签 |
| **联系人** | 「联系人 / 群聊」两个子标签，带实时数量；顶部可按名字搜索 |
| **模型** | 当前模型信息与能力说明 |
| **设置** | 生成参数、外观、导入、存档 |

右上角 **＋** 在「消息」「联系人」页出现，点开是「添加联系人 / 创建群聊」两个入口。

## 4. 联系人

### 4.1 新建

＋ → 添加联系人，填写：

| 字段 | 必填 | 说明 |
|---|---|---|
| 头像 | 否 | 内置 12 个头像 + 两位角色形象；也可从相册导入（自动居中裁成方形、缩到 256 px） |
| 名字 | **是** | 全局唯一，不能和已有联系人/群重名（@ 功能依赖名字唯一） |
| 说话方式 | 否 | 音色（6 选 1）+ 自动朗读开关，**只对这个联系人生效** |
| 人设 | 否 | 它是谁、怎么说话。**效果最强的字段**，建议 2–3 句 |
| 长期记忆 | 否 | 关于你的事实，例如"我叫阿哲，做 Java 后端，回答别太长" |

创建后直接进入聊天，空聊天页只显示：圆形头像 + 名字 + 人设介绍。

### 4.2 人设怎么写

好的人设包含三件事：**身份 + 说话方式 + 与你的关系**。

```
24 岁的插画师，说话温柔、句子短，偶尔用颜文字。知道我在准备考研，
会主动问我今天学了什么。
```

不好的写法：只写"你是一个助手"（模型会退化成通用口吻）；写超过 200 字的详细设定（1B 执行不稳定，容易只记住开头）。

### 4.3 修改设定

三种入口都能打开编辑面板：

- 聊天页顶栏右上角的**铅笔**；
- 空聊天页的**头像**；
- 联系人页每行右侧的**铅笔**。

面板底部有红色「**删除这个联系人**」；如果它还在某个群里，会提示会从几个群移除。

### 4.4 长期记忆（记忆卡）

两种方式，效果相同：

1. 在编辑面板的「长期记忆」里自由写；
2. **长按 AI 的某句回复** → 「存为长期记忆」→ 预填那句话，改成一句事实后保存。

记忆会**每次请求都注入**，不占聊天历史条数，所以聊到第 50 句也不会丢。

限制：一条 60 字、每人最多 30 条 / 合计 900 字。满了会提示先删（面板里每条右侧有 ×）。

群聊里存记忆，会存到**说这句话的那个 AI**身上，而不是群。

## 5. 聊天

### 5.1 发消息

- 输入后点右侧箭头，或按回车（**Shift+回车**换行）；
- 单条上限 2000 字；
- 生成过程中按钮变成「停止」，点一下会中断当前回答；如果是 @ 了多个人，会中断整条队列。

### 5.2 发图片

点输入栏左侧 **＋** → 选图 → 图上会出现在输入框上方（可点 × 取消）→ 输入问题后发送。

- 图片会先按「设置 → 图片长边」压缩（默认 1024 px）再送进模型；
- 看图比纯文字慢：1024 px 的图首字约 10 秒级；
- 历史里只保留最后一张图，更早的图片不重复发送，省上下文。

### 5.3 语音输入

点输入栏的**麦克风**，说话，识别结果会填进输入框（不会自动发送，可先改）。

用的是 SenseVoice 本地识别，不联网。识别在点麦克风后开始，说完再点一次结束。

### 5.4 朗读

两种：

- 每个联系人的「自动朗读」开关打开后，它的回复会自动读出来；
- 长按任意 AI 消息 → 「朗读」，按该联系人的音色读这一条。

音色切换是跟着联系人走的：小夏用女声、老张用男声，切聊天会自动换。首次切到某个新音色会有约 1 秒的加载。

### 5.5 长按一条 AI 消息

弹出操作面板：

| 选项 | 作用 |
|---|---|
| 存为长期记忆 | 存进这个 AI 的记忆卡（可编辑，60 字） |
| 复制 | 复制原文 |
| 朗读 | 用当前音色读一遍 |
| 分享 | 走系统分享 |
| 删除这条消息 | 只删这一条，不影响其他 |

## 6. 群聊

### 6.1 建群

＋ → 创建群聊 → 填群名、挑群头像、勾选成员（**2–10 人**）→ 创建。

群里每个 AI **保留自己的人设、长期记忆、音色、朗读开关**，互不串味。每次只有被点名的那位用自己的人设回答。

### 6.2 指定谁回答（@）

三种方式：

1. 点群聊顶部**成员头像条**里的头像；
2. 点某条消息旁的**小头像**；
3. **长按**任意头像约 0.5 秒。

都会在输入框插入 `@名字 `。一条消息可以 @ 多个人，他们会**按顺序各回答一次**（不是同时抢话）。

没有 @ 时，由上一位发言的 AI 接着说；第一次进群由第一位成员回答。

### 6.3 群设置

在「联系人 → 群聊」标签里点某一行的铅笔，可以：

- 改群名、换群头像；
- 增减成员（2–10 人）；
- 解散群聊（群里的 AI 本体不受影响）。

### 6.4 数量和上限

| 项目 | 上限 |
|---|---|
| 一个群的成员 | 10 |
| 群总数 | 40 |
| 联系人总数 | 300 |

到上限时会有提示，需要先删一些。

---

## 7. 搜索与删除

**搜索**：联系人页顶部输入框，**只按名字匹配**（人设、聊天内容不参与），切换「联系人 / 群聊」标签会自动清空关键词。

**删除**：

- **长按**消息列表或联系人页的任意一行 → 震动 → 确认框；
- 删联系人：会连同聊天记录一起删，并把它从所有群里移除；
- 长按群聊行：提示「解散群聊」；
- 普通点击仍然是进入聊天，取消没有任何副作用。

## 8. 设置逐项说明

### 生成

| 项 | 建议 |
|---|---|
| 深思模式 | 默认关。开启后先思考再回答，**延迟明显变长**，只在数学/逻辑题时开 |
| 温度 | 默认 0.70。想更稳定答同一样东西调低（0.3–0.5），想更有创意调高（0.9–1.1） |
| 最大输出 | 默认 768。长文写作调到 1024–1536；只问短答可降到 384 提速 |

### 多模态

| 项 | 说明 |
|---|---|
| 图片长边 | 默认 1024 px。看小字（票据、说明书）调到 1408–1600 更清楚但更慢；文字类 768 就够 |
| 视觉加速 | 只读显示。走 Adreno GPU（OpenCL）时识别快数倍，退回 CPU 会慢很多 |

### 外观与数据

| 项 | 说明 |
|---|---|
| 深色模式 | 手动开关 |
| 显示性能数据 | 每条回答下方显示 tok/s 与首字延迟，排查速度问题时很有用 |
| 模型包 | 导入模型 zip（覆盖式，文件已存在会跳过） |
| 音色包 | 导入额外音色 zip，右侧会显示"全部 6 个音色已就绪" |
| 分享当前聊天 | 导出纯文本，走系统分享 |
| 存档与恢复 | 见第 9 节 |
| 清空全部数据 | 联系人、群聊、聊天记录全删，**模型文件不受影响**，需二次确认 |

### 关于

显示版本、引擎信息、模型、本地占用、引擎路径，以及「重启本地引擎」按钮（引擎卡住时用）。

## 9. 存档与恢复（换机 / 重装）

### 9.1 导出

设置 → 存档与恢复 → **导出**。

文件落在：

```
/sdcard/Download/口袋CPM/koudai-存档-20261030-2249.json
```

每次导出都会新建一个带时间戳的文件，不会覆盖旧的。存档内容包含：全部联系人（含头像、人设、记忆、音色）、全部群聊、全部聊天记录（含图片）、以及设置项。

### 9.2 恢复

1. 把存档文件（或整个 `口袋CPM` 文件夹）拷到新手机；
2. 新机装好 App、导入模型包；
3. 设置 → 存档与恢复 → **恢复** → 选那个 json；
4. 确认后覆盖。

**恢复前会自动把当前数据导出一份**，选错文件也能退回。文件不是口袋 CPM 的存档会直接拒绝，不会动现有数据。

### 9.3 换机完整流程

```
旧机：导出存档 → 拷出 Download/口袋CPM/*.json
新机：装 APK → 导入模型包 zip（可选：音色包）→ 恢复存档
```

模型文件（1.7 GB）**不在存档里**，需要单独带模型 zip。

## 10. 常见问题

**Q：第一次打开要等很久？**
模型加载约 8–10 秒（672 MB 文本 + 1.06 GB 视觉）。之后退出再进是**秒开**——引擎会保持运行。想立刻释放内存，点通知栏的「结束引擎」，或等后台闲置 60 分钟自动释放。

**Q：它记不住自己的名字 / 会把别人当成自己？**
名字锁定有三层：提示词末尾的【名字锁定】、聊天历史里的角色隔离、以及输出后的自我纠正。仍不稳时，最快的办法是**给它写一句人设**——人设的效果远强于任何规则。

**Q：聊久了它忘了前面说过什么？**
上下文是 8192 tokens（约 3000 汉字），并且每次只带**最近 9 条**（群里 7 条）。想让它长期记住，用「长期记忆」或「存为长期记忆」，那部分不占历史额度。

**Q：回答很慢 / 首字要等很久？**
纯文字 1B 约 20–30 tok/s，首字 1–3 秒属正常。看图会慢很多（一张 1024 px 图约 10 秒级首字，整张票据约 1 分钟）。把「最大输出」调小、关闭深思模式可以更快。

**Q：切音色卡一下？**
正常。切换音色需要加载约 116 MB 的声学模型，约 1 秒。同一个音色再点不会重复加载。

**Q：语音输入没反应 / 听不到声音？**
检查系统是否给了麦克风权限；朗读无声时先确认该联系人的「自动朗读」是否打开，再用长按 → 朗读单独试一条。

**Q：手机发烫 / 内存紧张？**
推理是 CPU 满载运算，长时间对话会热，属正常。内存紧张时退出界面不会释放引擎（这是为了秒开），可以点通知栏「结束引擎」。

**Q：提示"这次的改动没能保存"？**
本地存储（约 5–10 MB）写满了。程序会自动丢弃最老的 12 张图片再试；仍失败时请先导出存档，再考虑删除旧聊天。

**Q：能装到别的手机上吗？**
可以，arm64 + Android 10 以上。注意 16 GB 内存以下的机器跑 1B 没问题，35B 不支持（需要 16 GB 以上，当前版本未开放入口）。

## 11. 性能参考（红米 K60 Pro，12 GB）

| 场景 | 表现 |
|---|---|
| 冷启动（加载模型） | 8–10 秒 |
| 热启动（引擎常驻） | 约 1 秒 |
| 纯文字生成 | 20–30 tok/s，首字 1–3 秒 |
| 看图（1024 px） | 首字约 10 秒级 |
| 看图（票据整张） | 约 1 分钟（GPU 加速；纯 CPU 约 7 分钟） |
| 引擎内存占用 | 约 930 MB（8192 上下文 + q8 KV） |
| 模型占用存储 | 约 1.7 GB（+ 音色包 476 MB） |

## 12. 数据与隐私

| 数据 | 位置 |
|---|---|
| 联系人、群聊、聊天记录、设置 | App 内部存储（WebView localStorage） |
| 模型 / 语音模型 | `/data/data/com.koudai.cpm/files/`（应用私有，非 root 无法读取） |
| 存档 | `/sdcard/Download/口袋CPM/`（公开目录，可拷走） |

- 除本机 `127.0.0.1:8080` 的推理进程外，App **不发起任何网络请求**；
- 卸载 App 会清空内部存储（聊天记录、模型），**存档和 Download 里的 zip 不受影响**；
- 存档文件是明文 JSON，含聊天内容，分享给他人前请注意。
